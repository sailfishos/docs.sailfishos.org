# Official Jolla TOHs

Official Jolla TOHs are The Orange, Kaamos Black, Snow White and Inari Blue.
The first three may be purchased from Jolla.
Inari Blue is gifted as part of the pre-order campaign to the purchasers of the first 10,000 devices.

## Memory chip

The memory chip in Jolla TOHs is 4 kibibytes arranged in 16 blocks of 256 bytes.
It is not write protected.
The content takes only 55-57 bytes leaving 15 blocks of 256 bytes empty.
The rest of the space is for those who would like to start tinkering with TOHs.

Read more about TOH memory content in [Jolla Phone (2026) The Other Half development](/Develop/Hardware/JP2601-TOH/#memory-chip-content).

The memory chip content is available in source format in [toh-content repository](https://github.com/sailfishos/toh-content)
and in binary format in [releases of the same repository](https://github.com/sailfishos/toh-content/releases).

## 3D models

For the sold TOHs, the 3D model can be obtained from [toh-designs repository](https://github.com/sailfishos/toh-designs).
